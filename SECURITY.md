# Security policy

This repository contains learning projects and prototypes. Do not assume that any application or smart contract is suitable for production use.

## Reporting a vulnerability

Please do not publish exploitable details, credentials or private data in a public issue. Contact the repository owner through the GitHub profile and include a concise description, affected path/version, impact and safe reproduction steps.

## Safe-use notice

- Never use example private keys, seed phrases or credentials with real assets.
- Do not deploy experimental contracts with funds.
- Review dependencies and configuration before running code.
- The presence of tests does not establish security or correctness.
