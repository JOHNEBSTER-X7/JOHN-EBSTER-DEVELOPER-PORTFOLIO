# Projects

Projects are grouped by engineering discipline. Each project should be self-contained with its own documentation, configuration and tests.

- `web3/` — smart contracts and blockchain applications
- `python/` — Python services, APIs and data tooling
- `full-stack/` — browser applications and backend services
- `ai/` — AI applications, RAG and agent workflows
- `cloud-devops/` — cloud infrastructure, containers and automation
- `fintech-data/` — financial data, analytics and reconciliation
