# Financial crime control matrix

| Control | Demonstration | Production requirement |
|---|---|---|
| KYC/KYB | Customer profile and reviewer gate | Identity, entity, beneficial ownership and ongoing due diligence |
| Sanctions/PEP | Small synthetic watchlist | Authoritative, frequently updated screening sources and fuzzy matching |
| Risk scoring | Transparent deterministic rules | Validated model, thresholds, governance and bias testing |
| Transaction monitoring | Value and jurisdiction rules | Calibrated scenarios, velocity, network and behavioural analytics |
| Investigation | Case assignment, notes and disposition | Secure workflow, access controls, evidence retention and QA |
| SAR workflow | Internal draft and review status | Jurisdiction-specific legal assessment and secure filing process |
| Audit | In-memory structured events | Tamper-evident immutable records and retention |
| Security | No real identity layer | SSO, MFA, RBAC, segregation of duties, encryption and monitoring |
