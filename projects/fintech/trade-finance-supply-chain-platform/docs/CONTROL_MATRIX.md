# Trade finance control matrix

| Control | Prototype behaviour | Production requirement |
|---|---|---|
| Party due diligence | Pending/verified/rejected status | KYC, KYB, AML and sanctions provider integrations |
| Document completeness | Finance-type checklist | Authenticity, tamper and fraud verification |
| Credit risk | Explainable deterministic score | Validated underwriting model and governance |
| Lender exposure | Fixed currency-specific facility limit | Real lender mandates and concentration limits |
| Maker-checker | Reviewer ID differs from applicant | Authenticated role-based approval and dual control |
| Funding | Approved-state transition | Bank/payment rail settlement and ledger posting |
| Audit | In-memory structured events | Immutable, retained and access-controlled audit |
| Compliance | Not implemented | Jurisdictional legal, regulatory and reporting controls |
