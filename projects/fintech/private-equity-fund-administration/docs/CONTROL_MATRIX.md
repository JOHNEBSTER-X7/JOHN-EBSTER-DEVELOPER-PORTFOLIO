# Fund administration control matrix

| Area | Demonstration | Production requirement |
|---|---|---|
| GP/LP onboarding | Verification flag and reviewer separation | KYC/KYB, beneficial ownership, sanctions and eligibility |
| Fund terms | Target, fees, carry and hurdle basis points | Executed legal documents and controlled amendments |
| Subscription | Accepted/rejected workflow | AML, suitability, source of funds and signed documents |
| Capital calls | Pro-rata integer allocation | Notice, due-date tracking, bank reconciliation and default handling |
| Portfolio | Cost and fair value records | Valuation committee, policy, evidence and independent review |
| NAV | Sum of investment fair values | Full fund accounting, liabilities, fees, FX and accruals |
| Waterfall | Simplified carry estimate | LPA-specific waterfall, preferred return, catch-up and clawback |
| Investor statements | On-demand demo statement | Secure distribution, approval and investor access controls |
| Audit | In-memory event log | Immutable durable audit and retention |
