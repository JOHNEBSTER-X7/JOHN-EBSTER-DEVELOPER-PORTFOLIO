# Private credit control matrix

| Area | Demonstration | Production requirement |
|---|---|---|
| Party onboarding | Verified status and reviewer separation | KYC/KYB, beneficial ownership, sanctions and source-of-funds checks |
| Underwriting | Independent approve/reject gate | Financial analysis, credit bureau data, policy and model governance |
| Facility | Commitment and lifecycle register | Executed legal documentation and controlled amendments |
| Syndication | Lender participation allocations | Eligibility, participation agreements and cash settlement |
| Drawdown | Facility commitment check | Conditions precedent, utilisation evidence and dual approval |
| Servicing | Monthly amortisation and payment allocation | Contractual day-count, payment rails, arrears and reconciliation |
| Collateral | Description and manual valuation | Ownership, valuation, perfection, lien priority and monitoring |
| Covenants | Manual leverage and coverage observations | Verified financial data, testing calendar and breach remediation |
| Audit | In-memory event history | Durable tamper-evident audit and retention |
| Security | No identity layer | SSO, MFA, RBAC, segregation of duties and encryption |
