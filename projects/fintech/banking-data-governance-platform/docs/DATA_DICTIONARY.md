# Metadata dictionary

| Entity | Key attributes |
|---|---|
| Dataset | Name, domain, description, owner, steward, classification, system of record, tags |
| Schema | Dataset, sequential version, fields, draft/approved/retired status, approver |
| Field | Name, type, required, sensitive marker, description |
| Quality rule | Field, rule kind, severity, allowed values, enabled state |
| Finding | Dataset, rule, record index, field, severity and message |
| Issue | Dataset, linked finding, title, owner and lifecycle status |
| Lineage edge | Source dataset, target dataset, relationship |
